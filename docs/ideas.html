Two strategic vectors choose one

Every idea below slots into one of two distinct product trajectories. The first ten things you ship differ a lot depending on which one you bet on.

Vector A · platform
FACTS as the agent-OS layer
Every coding agent uses FACTS context to be better. Semantic search, NL summaries, skill auto-generation, Q&A surfaces. High moat, ambiguous (whose LLM? whose tokens?), weeks of work. Look at categories B (AI tooling) and J (FACTS platform).
Vector B · reach
FACTS in every dev workflow
GitHub Action, IDE plugins, public hosted service, integrations. Lower moat, install-base compounds, the agent layer benefits from more analyzed projects anyway. Look at categories C (Dev UX), D (security), and J (platform).
Hybrid worth flagging

#21 (skill auto-generator) + #45 (GitHub Action) together make FACTS the thing that puts agent context into every PR review without any opt-in beyond gh extension install factstack. Cheapest move that touches both vectors.
