Decision: Path A before Path B

Committed · Phase 2A shipped 2026-05-27
Deepen the security tier into the artifact pipeline before shipping the VS Code extension.

The Credentials + Vulnerabilities UI just landed but the artifact itself doesn't carry CVE or dependency data — that means factstack analyze --json can't gate CI on it, and the MCP server can't serve it to agents. Closing that asymmetry first makes every subsequent surface (CLI, MCP, future VS Code, future Chrome ext) inherit the security tier for free.

Path B (VS Code extension) follows once the artifact carries the full security shape. Reach matters; but reach over an incomplete platform compounds the asymmetry. Sequence: A finishes (~3-4 days), then B starts (~1 week).

2A.5 · Hybrid feature: skill emitters + PR risk gate shipped 2026-05-28

Effort 1 day Scope ideas #21 + #45 combined

The two highest-leverage items from the 100-ideas board shipped together. They share a backbone (a per-format renderer over the existing AgentArtifact), so building them as one feature was cheaper than building them sequentially.

Out of scope (deferred): the actual GitHub Action action.yml, the gh extension package, and any Marketplace publishing. The core feature ships first; distribution surfaces come in a follow-up once the user has dogfooded the CLI verbs against real PRs.

What landed

New package: @factstack/skills — pure isomorphic, sits at the same tier as @factstack/core. Three renderers (Claude SKILL.md, Cursor .cursorrules, GitHub Copilot copilot-instructions.md) fed from one canonical SkillSpec intermediate representation. Orchestrator buildSkillsTo(writer, agent, human, formats?) mirrors the existing writeArtifactsTo shape.

Schema extension: DiffArtifactSchema grew a vulns: { new[], fixed[], severityShift } field (v0.7). The severity-shift score is weighted (critical: 4, high: 3, medium: 2, low: 1) so a PR that adds one critical and fixes one low correctly shows +3 rather than the misleading 0 a pure count delta would show.

Two CLI verbs: factstack export-skills [target] emits the three skill files at the project root; factstack ci-report [target] --base <snapshot> emits a markdown diff report suitable for gh pr comment --body-file and includes a --fail-on-shift <n> gate that exits non-zero when severity worsens past a threshold. The shared loadDiffEndpoint + resolveDiffEndpointArg helpers are reused between diff and ci-report.

Tests: 38 in @factstack/skills (extract + 3 renderers + orchestrator) · 7 new vuln-diff cases in @factstack/core · 22 in apps/cli for the markdown report. All 672 workspace tests green.

Dogfooded: ran export-skills against FACTS itself — three real skill files now live at .claude/skills/factstack-factstack/SKILL.md, .cursorrules, and .github/copilot-instructions.md. ci-report against a 3-day-old snapshot correctly surfaced the 2 new high-severity GHSAs in our own deps with severity shift +6.
