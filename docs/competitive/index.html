The same thesis, five altitudes

All four tools agree on the premise Sourcegraph states outright: “agents see only fragments of the codebase, rebuilding context for each task.” They differ in what they optimize — and they’re largely complementary, because each attacks a different part of the token bill.

  • FACTS optimizes encoding — tokens-per-fact, via the FactsPack wire format — and uniquely serves a human/CXO audience too.
  • GrapeRoot optimizes selection & timing — pre-inject the right files so the agent explores less.
  • Graphify optimizes graph intelligence & reach — multi-modal knowledge graph, queried instead of grepped, installed everywhere.
  • Sourcegraph optimizes scale & completeness — index every repo, feed any agent via an SCIP-powered MCP.
  • Neo4j isn’t a tool here — it’s the graph database any of them could store the graph in.

Where Neo4j fits

Neo4j is a different category — the graph database (labeled property graph, Cypher, GDS algorithms, vector index/GraphRAG). It’s the optional storage/query backend beneath a code-intelligence tool: Graphify can push to it; Sourcegraph and FACTS deliberately don’t use one (Postgres / SQLite). Lesson for FACTS: borrow the concepts, skip the server — property-graph schema, a Cypher-subset compiled to SQLite CTEs, PageRank for “god nodes”, Leiden for modules, MERGE-style incremental upserts, and GraphRAG-style graph-aware retrieval — while keeping SQLite + FactsPack as the committable, zero-infra substrate. Optionally expose facts export --neo4j. Full detail in neo4j.html.

What FACTS should borrow (top of the list)

  1. ★ Push / pre-injection [GrapeRoot] — rank relevant files/symbols and inject a FactsPack-encoded context block before the agent acts. Selection × encoding.
  2. ★ Confidence tags [Graphify] — EXTRACTED/INFERRED/AMBIGUOUS on edges; on-brand with FACTS determinism.
  3. ★ NL query → minimal subgraph [Graphify + Sourcegraph Deep Search] — beyond fixed verbs; citation-grounded.
  4. ★ Ingest SCIP [Sourcegraph] — many languages with compiler-grade precision, no per-language extractor.
  5. ★ “Make every token count” MCP framing + reproducible session benchmark [Sourcegraph + both] — prove FactsPack at the task level.
  6. Graph algorithms [Neo4j GDS] — PageRank importance, Leiden modules, blast-radius paths.
  7. Skill + 1-line installer + query-first hooks [Graphify/GrapeRoot] — the adoption engine.
  8. Committable graph + git hooks + PR impact [Graphify] — make .facts/ a team artifact.

FACTS’s moat — keep while borrowing

FactsPack wire format (no rival has a token-optimized transport — even Sourcegraph ships JSON/SCIP), the dual-audience CXO dashboard (agent-only rivals have nothing for humans; Sourcegraph validates this with Code Insights), deterministic/committable output, and built-in secrets detection.
