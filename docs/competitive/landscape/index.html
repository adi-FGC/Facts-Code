AI Coding & Code-Intelligence — Market Landscape

A CIO-grade scan of the tools adjacent to FACTS / FactsPack: context/token reduction, coding-agent context engines, semantic code search & code-graphs, code-intelligence infrastructure, AI testing, and engineering-intelligence dashboards. ~70 tools across six categories, researched live and captured 2026-06-06. Each category links to a full dossier; figures are point-in-time.

The stack, by layer

These categories form a layer cake. The bottom layer (infrastructure) is what everything else is built on; the top layers (agents, dashboards) are what users touch. FACTS spans an unusual diagonal: it sits on the infrastructure layer (its own extractor + graph) but ships both an agent-facing wire format and a human/exec dashboard.

What this means for FACTS

✓ Validated by the market

  • Token-cheap context is a real category — an entire layer (cat 1) exists just to shrink payloads.
  • Repo-map + PageRank works — Aider proves deterministic, local, budgeted context selection (FACTS's pre-injection feature).
  • Structural > embeddings for precision — Serena (~25k★) and JetBrains PSI show agents want authoritative symbol answers, not fuzzy chunks.
  • Behavioral code analysis is the exec wedge — CodeScene monetizes exactly the git-churn × complexity hotspot that FACTS already has the inputs for.

↻ Borrow now (per category)

  • 1: yek's git-history ranking; Repomix's AST skeleton rows.
  • 2: Aider's personalized-PageRank loop; Cursor's Merkle incremental invalidation.
  • 3: Serena's MCP tool conventions; blarify's SCIP-first fallback; Potpie's incremental graph update.
  • 4: web-tree-sitter + a scope-graph layer; optional SCIP ingest for compiler-grade multi-language.
  • 5: graph-driven impact-based test selection (Diffblue Optimize idea).
  • 6: hotspots, change coupling, knowledge-risk, health-trend, DORA anchoring.

★ Uncontested (FACTS's moat)

  • A compact tabular wire format — every cat-1 tool emits flat text/XML for chat; none emit typed columns + relational keys.
  • Deterministic, committable, diffable — incompatible with the LLM-based compressors and embedding indexes that dominate.
  • Dual audience — agent JSON/pack and an exec dashboard from one pass; cat-2/3 serve agents, cat-6 serves execs, nobody does both.
  • Local + isomorphic (browser+Node) — most graph tools need Neo4j/Qdrant or a cloud; FACTS needs neither.
  • Built-in secrets/risk + intent — security and CXO-narrative in the same artifact.

CIO build-vs-buy lens

  • Adopt (open infrastructure): tree-sitter/web-tree-sitter for parsing, the SCIP format for compiler-grade ingest, LSP for live symbol truth, the MCP tool conventions Serena popularized. Don't hand-write parsers or invent a protocol where an open one exists.
  • Build (the differentiated core): the FactsPack wire format, the deterministic graph + ranking, graph-aware pre-injection, and the dual-audience (agent + exec) output. No vendor sells this combination; it is the defensible center.
  • Watch (fast-moving entrants): knowledge-graph context engines (Augment, Tabnine Enterprise), behavioral analysis (CodeScene), and per-review-priced review agents (Greptile). These validate demand and signal where the category is heading.
  • Avoid as dependencies: heavyweight or closed substrates — Neo4j-as-default, CodeQL's closed engine, Kythe (maintenance-mode), and any cloud-upload requirement — all of which break the local/zero-infra/committable invariant.
